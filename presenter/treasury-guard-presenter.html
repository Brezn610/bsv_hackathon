Treasury Guard
Base decides. BSV moves the money. The owner can always leave.

Glossary

G or Esc to close
x402
Paying per request over HTTP 402: 0.001 aUSD per signed price, 0.01 aUSD per post.
Airnode (first-party)
The data provider’s own signer. CoinPaprika and TwitterAPI.io sign their answers at the source.
AirnodeHub
API3’s catalog of signed APIs. It had no BSV/USD feed on Nodary and no feed of official statements.
EIP-191 signature
The Airnode’s signature on a response. TreasuryGuard checks it came from the vault’s Airnode (else SignerMismatch).
request hash
Fingerprint of exactly which request was signed. Must equal the vault’s request (else WrongRequest).
aUSD
The test dollar token paid to the Airnodes over x402. The Runner (vault 8) is capped at 0.5 aUSD/day for data.
Base Sepolia
Ethereum L2 testnet, chain 84532. TreasuryGuard decides here.
intent
A budgeted SPEND on Base with a hard cap in sats. The only way the agent can move money.
settle
Records the BSV txid the Orchestrator finds via the TGv1 receipt on WhatsOnChain. Base does not verify BSV.
HTTP 402 / BRC-121
Payment Required: the BSV agent pays per call in sats, e.g. 100 sats to the Analyst API. BRC-121 on BSV.
OP_RETURN receipt (TGv1)
Data in every withdrawal: TGv1 84532 0x8e38…7773 vault intent. Links the BSV tx to the Base intent.
UTXO
An unspent BSV output. The BSV agent pays from exactly the withdrawn output, e.g. 8519e2…:0.
non-custodial
BSV agent and Watcher can only spend together, inside the cap. Only the owner can move coins alone.
owner exit
Script branch OP_ELSE <owner> OP_CHECKSIG. The owner withdraws alone; proven on mainnet 30 Oct.
Watcher
Independent process. Co-signs only what Base approved, after checking the real transaction bytes.
Orchestrator
API3 side, holds the vault-5 EVM key. Buys signed data over x402, calls submitEvent, submitPrice and settle.
Runner (vault 8)
Autonomous loop on vault 8: buys a signed price every 10 min (2 min near the breaker), 84 cycles in 14 h.
BSV agent (tg auto)
Picks up intents, proposes the transaction to the Watcher, broadcasts it and pays over HTTP 402.
journal
The watcher’s record: “reserved” before signing, survives restarts, file lock. One transaction per intent.

settle records the BSV txid the orchestrator finds via the TGv1 receipt on WhatsOnChain; Base does not verify BSV. Hedges are recorded on Base and move no BSV in this submission.
